# Sprint_5
В этом проекте написаны автотесты для сервиса Stellar Burgers. Это космический фастфуд: можно собрать и заказать бургер из необычных ингредиентов.

документ tests_regictration включает в себя тесты:
проверку успешной регистрации. Поле «Имя» должно быть не пустым; в поле Email введён email в формате логин@домен: например, 123@ya.ru. Минимальный пароль — шесть символов.
Проверку ошибки для некорректного пароля.

Документ tests_authorization включает в себя тесты:
вход по кнопке «Войти в аккаунт» на главной,
вход через кнопку «Личный кабинет»,
вход через кнопку в форме регистрации,
вход через кнопку в форме восстановления пароля.

Документ tests_page_transitions включает в себя тесты:
Переход в личный кабинет/Проверку перехода по клику на «Личный кабинет».
Переход из личного кабинета в конструкторб проверку перехода по клику на «Конструктор» и на логотип Stellar Burgers.
Выход из аккаунта, Проверку выхода по кнопке «Выйти» в личном кабинете.

Документ tests_constructors включает в себя тесты:
Проверка, что работают переходы к разделам:
«Булки»,
«Соусы»,
«Начинки».
